
# AI Usage Disclosure

AI tools were used as development assistants during this project.

## Areas Where AI Assistance Was Used

- Understanding the assignment requirements and planning the application structure.
- Learning and troubleshooting ASP.NET Core, Entity Framework Core, PostgreSQL, and React.
- Understanding API design, database relationships, and admission reservation logic.
- Debugging errors during backend and frontend development.
- Understanding Dockerfiles and Docker Compose configuration.
- Preparing project documentation and improving code readability.
- Reviewing test scenarios, including concurrent admission requests.

## Developer Responsibilities

- Reviewed and applied suggested changes to the project.
- Ran the application locally and through Docker Compose.
- Tested API endpoints and frontend workflows.
- Ran automated tests against a separate PostgreSQL test database.
- Verified the application behavior and corrected issues during development.

AI assistance was used as a supporting tool. The final implementation and submitted project were reviewed and tested by the developer.
